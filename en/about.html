About MotmaenBash

MotmaenBash is a free, independent, open-source project that helps people recognize phishing and online fraud.

Developer

This project is developed by Milad Nouri. The aim is a simple, practical tool, continued with help from users and volunteer developers.

Transparency and security come first, so the project code is published on GitHub.

You can help improve it. Suggestions and contributions on GitHub are welcome.

View on GitHub

Goals

  • Help people recognize online fraud, phishing, and ways to avoid them
  • Offer simple tools
  • Lower the risk of phishing and online fraud
  • Keep the project updated as new scams appear

What MotmaenBash does

  • A browser extension that checks online payment gateways
  • An Android app that checks SMS messages, links, and suspicious apps
  • A database that is updated as new scams appear
  • A way for people to report suspicious cases
