Version 1.0.4
  • Suspicious apps can now be flagged from the install source and the combination of permissions they request, without relying on the database
  • Fixed a crash on Android 13 and errors while checking apps
  • The new-SMS window is off by default, and its setting was added to the intro
  • Manual database refresh can be used again after 15 minutes instead of 1 hour, and automatic refresh can be set to 12 hours
  • Added a “Trust MotmaenBash” step to the intro
  • Fixed some statistics issues
  • Fixed typos, improved the interface and the on-device database, and fixed a few other bugs…
Version 1.0.3 beta
  • Fixed repeated warnings when opening a suspicious site
  • Small improvements to the settings screen
  • Fixed a few other minor bugs
Version 1.0.2 beta
  • Improved the daily tip card
  • Fixed English SMS text rendering too small in the new-SMS window
  • Fixed repeated warnings for the same address in some cases
  • Improved database updates and stopped endless retries after an error
  • Fixed duplicated text in the changelog window
  • Small improvements to the warning interface
  • Fixed a few other minor bugs
Version 1.0.1 (experimental beta)
  • Removed extra permissions added by the Firebase libraries
  • Added an in-app changelog
  • Improved scrolling on several screens
  • Fixed text layout on devices with a large font
  • The sender number in the new-SMS window is now a link
  • Removed the footer from the new-SMS window
  • Added a setting for the new-SMS window
  • Fixed the alert sound when a new SMS arrives
  • Improved the icon and title of the new-SMS window
  • Removed extra blank lines from the SMS text shown in the window
  • The new-SMS window now closes with the Back button
  • The app no longer appears in the list of apps that open links
  • Improved checking of incoming SMS
  • And a few other small fixes…
